# LogiCh

Joomla 6 extensions maintained by [Logical Choice](https://logical-choice.hr): the template **LogiCh**, the package
**LogiCh Media** (photos and attachments for articles, photo slider module) and the extensions made for single sites
(child templates of LogiCh, site-specific components). GPL-2.0-or-later.

This repository holds the **releases** and the **update server** (`updates/*.xml`): sites with LogiCh installed
find new versions in *System → Update → Extensions*. Download the zip of the latest release and install it via
*System → Install → Extensions*.

| Extension | Update XML |
|---|---|
| Template `tpl_logich` | `updates/tpl_logich.xml` |
| Package `pkg_logichmedia` | `updates/pkg_logichmedia.xml` |
| Template `tpl_logich_vrtic` (child of LogiCh, Dječji vrtić Dekanovec) | `updates/tpl_logich_vrtic.xml` |
| Template `tpl_logich_hisa` (child of LogiCh, Hisa d.o.o.) | `updates/tpl_logich_hisa.xml` |
| Component `com_jelovnik` (weekly kindergarten food menu, Dječji vrtić Dekanovec) | `updates/com_jelovnik.xml` |

Requirements: Joomla 6, PHP 8.3+.
