# LogiCh

Joomla 6 template **LogiCh** and package **LogiCh Media** (photos and attachments for articles, photo slider module)
by [Logical Choice](https://logical-choice.hr). GPL-2.0-or-later.

This repository holds the **releases** and the **update server** (`updates/*.xml`): sites with LogiCh installed
find new versions in *System → Update → Extensions*. Download the zip of the latest release and install it via
*System → Install → Extensions*.

| Extension | Update XML |
|---|---|
| Template `tpl_logich` | `updates/tpl_logich.xml` |
| Package `pkg_logichmedia` | `updates/pkg_logichmedia.xml` |

Requirements: Joomla 6, PHP 8.3+.
